# Results

This directory contains compact artifacts supporting the paper:

- `model_checkpoints/`: released model state dictionaries and run configs
- `benchmark_runs/`: selected complete IdentityPFN evaluation runs
- `baselines/`: final cross-source Splink and pyJedAI runs
- `field_evidence_diagnostics/`: evidence-pattern diagnostic outputs
- `field_type_sweeps/`: field-type sensitivity outputs
- `paper_benchmark_tables/`: intermediate and presentation-ready table inputs

Profiles, partial runs, smoke outputs, raw ComEM prompts/responses, and source
benchmark records are intentionally excluded.

Historical files retain their original run IDs and model labels. These should
be used to trace reported values, not interpreted as separate released model
APIs.
