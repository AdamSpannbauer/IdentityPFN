# Area Code Data

`area_codes_bennetyeedogorg_ucsd_pages_area_html.csv` was derived from Bennet
Yee's area-code listing, formerly hosted at UCSD:

https://cseweb.ucsd.edu/~bsy/area.html

The page describes itself as a community-maintained listing, not an authoritative
telephone-company or NANPA data source. Use this file only for plausible
synthetic data generation, not for production validation or telecom lookups.
